Políticas de privacidad

Ultima actualizacion: 24 de agosto de 2026

NatureAR es una familia de aplicaciones moviles de realidad aumentada para recorridos en areas silvestres protegidas de Costa Rica, incluyendo Juan Castro Blanco, Arenal, Cano Negro y Volcan Tenorio. Esta pagina explica como se manejan los datos y cuales condiciones aplican al uso de las aplicaciones.

1. Informacion que recopilamos

Las aplicaciones NatureAR recopilan unicamente la informacion necesaria para funcionar correctamente.

  • Datos tecnicos del dispositivo, como sistema operativo, version de la app y registros de error.
  • Informacion de uso anonima para mejorar estabilidad, contenido y rendimiento.
  • Permiso de camara cuando el usuario utiliza funciones de escaneo o realidad aumentada.
  • Ubicacion aproximada solo cuando una funcion especifica lo requiere y el usuario la autoriza.

2. Uso de la informacion

La informacion se utiliza para operar, mantener y mejorar la experiencia de NatureAR.

  • Permitir el reconocimiento de marcadores y contenido de realidad aumentada.
  • Corregir errores, mejorar el rendimiento y asegurar compatibilidad con dispositivos.
  • Entender de forma anonima como se usan las aplicaciones.
  • Proteger la seguridad y estabilidad del servicio.

3. Permisos de la aplicacion

Las aplicaciones pueden solicitar permisos del dispositivo segun la experiencia habilitada.

  • Camara: necesaria para escanear marcadores y activar experiencias de realidad aumentada.
  • Ubicacion: opcional, utilizada solo para funciones basadas en contexto geografico cuando el usuario la autoriza.
  • Almacenamiento: puede utilizarse para archivos temporales o recursos necesarios de la aplicacion.

4. Compartir datos

NatureAR no vende ni alquila datos personales. La informacion anonima o agregada puede utilizarse con fines academicos, educativos, tecnicos o de mejora del proyecto, sin identificar personalmente a los usuarios.

5. Seguridad y almacenamiento

Se aplican medidas razonables para proteger la informacion contra acceso no autorizado, alteracion, divulgacion o destruccion. Ningun sistema es completamente infalible, por lo que el proyecto revisa y mejora sus practicas cuando sea necesario.

6. Condiciones de uso

Al usar NatureAR, el usuario acepta utilizar la aplicacion de forma responsable durante su visita.

  • La aplicacion es una herramienta educativa e informativa; no reemplaza senalizacion oficial, instrucciones del parque ni indicaciones de seguridad.
  • El usuario debe respetar senderos, normas del area protegida y recomendaciones del personal autorizado.
  • El contenido puede actualizarse, corregirse o modificarse conforme avance el proyecto.
  • El uso de la camara o ubicacion depende de los permisos otorgados por el usuario en su dispositivo.

7. Derechos del usuario

El usuario puede revocar permisos desde la configuracion de su dispositivo y contactar al equipo para consultas relacionadas con privacidad, soporte o eliminacion de datos proporcionados voluntariamente.

8. Cambios en esta politica

Esta politica puede actualizarse para reflejar cambios en las aplicaciones, requisitos de Play Store o mejoras del proyecto. La version vigente estara disponible en esta pagina.
